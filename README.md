# OENGO Merchant Application (`oengo-merchant`)

> **Merchant, Restaurant & Catalogue Management Application**  
> Governed by the OENGO Product Architecture & Commerce Engineering Organizations.

## 1. Domain Ownership
This repository authoritatively owns the **Merchant Business Portal**:
- **Capabilities**: Store profile management, catalogue & menu CRUD, incoming order fulfillment workflows, real-time revenue analytics.
- **Backend Coupling**: Interacts with `oengo-api` and `oenexa-pay` via strictly documented REST/gRPC endpoints.
